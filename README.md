# Computer Science for Vibe Coders

A free, plain-English computer science course for people who build apps with AI tools (Lovable, Cursor, Claude, ChatGPT, Grok). A side project by Johnder Perez.

Static site built with [Astro](https://astro.build). Content lives in `src/data/` and `src/pages/`.

```bash
npm install
npm run dev     # local dev server
npm run build   # static build to dist/
npm run check   # verify every page built with SEO tags
```

Workflow: branch → pull request → CI → merge. `main` auto-deploys.
